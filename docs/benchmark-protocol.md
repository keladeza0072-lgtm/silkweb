# Locked experimental controls

- A is an unclarified, natural vague request and **not** the primary evidence.
- B is the fair control: clarified requirements, no Silk Web tools.
- C is the assisted treatment: identical clarified requirements and Silk Web
  MCP/registry enabled.
- Use Muse Spark 1.3, same model build, reasoning effort, max model steps,
  approvals, starting commit, dependency lock, machine resources, and isolation.
- Keep hold-out tests separated so neither agent has access to them.
- Record every attempt, test failure, intervention, tool call, elapsed time,
  coding-model spend, and Librarian spend; compare B vs C.
- Never label a test passing until the independent harness executes it.
