# Reservation API starter

This Node.js 24 TypeScript project is a minimal starting point for the
reservation API task. The HTTP server intentionally returns NOT_IMPLEMENTED
until the requested functionality is added.

- `npm ci` installs the exactly pinned dependencies.
- `npm run build` compiles TypeScript under `src/` to `dist/`.
- `npm start` runs the compiled HTTP server.
- The functional requirements are supplied separately in the task prompt.

There is no completed booking implementation in this starter. Develop,
validate and document the runnable API in this project.
